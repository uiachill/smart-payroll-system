# Smart Payroll System

A modern employee salary calculation website built as a responsive payroll dashboard.

## Included features
- Dashboard overview with KPI cards
- Employee management with search and filtering
- Attendance and sales tracking tables
- Allowance management module
- AI payroll processing screen
- Salary calculation logic based on base salary, working days, allowances, insurance, and tax
- Export to CSV and print payslips

## Run locally
Open `index.html` in a browser.

## Project structure
- `index.html` – main layout and UI screens
- `style.css` – styling and responsive dashboard design
- `app.js` – mock data and interactive payroll logic

## Notes
This version uses realistic mock data to demonstrate the payroll system flow and UI structure. It is ready to be connected to a backend or database later.
